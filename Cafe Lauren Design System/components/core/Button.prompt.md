Text button for actions — one charcoal `primary` per view, sage `accent` for approving/confirming (e.g. "Approve menu", "Send to Instacart").
```jsx
<Button variant="accent" icon="shopping-cart">Send to Instacart</Button>
<Button variant="secondary" size="s" icon="plus">Add request</Button>
```
- variants: primary · accent · secondary · ghost · danger; sizes s 32 / m 40 / l 48px.
- Labels are sentence case verbs: "Plan the week", not "PLAN WEEK".
